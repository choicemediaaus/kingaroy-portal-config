# Portal options: the brief every new portal is built from

Started 2026-09-28 for Kingaroy (DECISIONS.md D4). These are PLATFORM
options that every client gets. The document moves to the platform repo
once that exists.

Each question is answered once per new portal. "Kate" marks an option
Kate listed. "OzWear" marks one drawn from OzWear portals already built
(Kids ELC, CCCT, South Burnett Council, QH, Redeemer). "Scope" means it
comes from the platform scope.

## 1. Structure and who can get in

| Question | Choices | Source |
|---|---|---|
| How is the portal set up? | One portal for the whole organisation · one portal per centre · a group portal with centres inside it | Scope §5.1, OzWear (CCCT multisite) |
| How do staff get an account? | We upload a staff list · staff sign themselves up · sign-up limited to the organisation's email domain | Scope §7.2 |
| Member approvals: does someone approve new sign-ups? | No · yes, the centre manager/director · yes, the organisation admin. (OzWear does not want to be the approver.) | Kate, OzWear (CCCT) |
| Who removes staff who leave, and what happens to their unused budget? | Centre manager · organisation admin; unused budget is lost or returned to the centre | OzWear (CCCT) |
| Director-only ordering page (bulk/centre supply)? | No · yes | OzWear (Kids ELC, CCCT), Scope §7.6 |
| Director-only products or prices? | No · yes (list them) | Scope §6 |

## 2. Budgets

| Question | Choices | Source |
|---|---|---|
| A budget per staff member? | No · yes, $ amount | Kate, OzWear (SBC $401.50/yr) |
| A budget per centre? | No · yes, $ amount | Kate, OzWear (CCCT) |
| Budget period | Financial year · calendar year · custom dates · from each person's start date | Scope §7.7, OzWear (SBC) |
| At the end of the period | Reset · roll over unused balance | Scope §7.7, OzWear (CCCT rolls over, SBC doesn't) |
| New starters | Full allowance straight away · part now, the rest after a set time (e.g. $110 now, $110 after 3 months) | OzWear (Kids ELC) |
| Released all at once, or centre by centre through the year? | All at once · by schedule | OzWear (Kids ELC) |
| What the budget covers | Garments only · garments + logo/embroidery · + freight · GST included or not | Scope §7.7, OzWear (SBC) |
| Separate budgets for garments and for logo/embroidery? | No · yes | OzWear (SBC) |
| When the budget runs out | Block the order · pay the difference by card · send for approval | Scope §7.7 |
| Reminders before a budget expires? | No · yes, how far ahead | OzWear (Kids ELC coupon expiry) |
